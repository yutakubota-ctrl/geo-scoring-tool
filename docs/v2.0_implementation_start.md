## トラブルシューティング

### BigQuery接続エラー
```
原因: サービスアカウントの権限不足
解決: BigQuery Admin権限を付与
```

### API呼び出しエラー
```
原因: レート制限超過
解決: tenacityでリトライ実装、または有料プラン検討
```

### 文字化け
```
原因: Windowsのコンソール文字コード
解決: UTF-8を強制（環境変数 PYTHONUTF8=1）
```
