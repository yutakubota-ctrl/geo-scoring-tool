## 5. Gem_02: Gap_Strategist（詳細設計）

### 5.1 役割

**動画の4つの競合分析手法を統合し、優先順位付きロードマップを生成**

### 5.2 統合する分析手法

#### 5.2.1 GRC順位差分分析（動画4）

```python
def analyze_grc_gap(own_domain: str, competitor_domain: str) -> Dict:
    """
    GRCの順位データから自社・競合の差分を分析

    動画手法:
    - トップ10以内の獲得数を比較
    - カテゴリ別（製品名、一般キーワード等）の勝敗を集計
    """
    # GRCのCSVデータを読み込み
    grc_data = pd.read_csv("grc_export.csv")

    own_top10 = grc_data[(grc_data['domain'] == own_domain) & (grc_data['rank'] <= 10)]
    comp_top10 = grc_data[(grc_data['domain'] == competitor_domain) & (grc_data['rank'] <= 10)]

    return {
        "own_top10_count": len(own_top10),
        "competitor_top10_count": len(comp_top10),
        "gap": len(comp_top10) - len(own_top10),
        "losing_keywords": comp_top10['keyword'].tolist()
    }
```

#### 5.2.2 Ahrefsキーワードギャップ（動画5）

```python
def analyze_ahrefs_gap(own_domain: str, competitor_domain: str) -> Dict:
    """
    Ahrefsのキーワードギャップ機能を活用

    動画手法:
    - 競合が獲得していて自社が獲得できていないキーワード群を抽出
    - トラフィックポテンシャルの差を明確化
    """
    # Ahrefs MCP経由でデータ取得
    gap_keywords = ahrefs_mcp_client.get_keyword_gap(
        target=own_domain,
        competitors=[competitor_domain]
    )

    # トラフィック差分の計算
    total_traffic_gap = sum([kw['volume'] for kw in gap_keywords])

    return {
        "gap_keywords_count": len(gap_keywords),
        "total_traffic_potential": total_traffic_gap,
        "top_opportunities": gap_keywords[:10]  # 上位10件
    }
```

#### 5.2.3 ページ要素比較（動画6）

```python
def compare_page_elements(own_url: str, competitor_urls: List[str]) -> Dict:
    """
    ページ内の要素（料金、口コミ、FAQ等）の有無を比較

    動画手法:
    - 対象URLを複数渡し、ページ内に含まれる要素を「マルバツ表」で出力
    """
    # Claudeでページ内容を分析
    analysis = claude_api.analyze_page_elements(
```

### 5.3 優先順位付けロジック

**動画の示唆**:
```
「集計・可視化はAIが圧倒的だが、
優先順位付けや戦略への落とし込みは人間が行う」
```

**実装**:
```python
def prioritize_tasks(gap_analysis: Dict) -> List[Dict]:
    """
    Impact × Effort マトリクス + Human-in-the-Loop
    """
    # Step 1: AIが初期スコアリング
    tasks = []
    for gap in gap_analysis['gaps']:
        impact_score = calculate_impact(gap)  # トラフィック・CV影響
        effort_score = estimate_effort(gap)   # 実装難易度

        tasks.append({
            "description": gap['description'],
            "impact": impact_score,
            "effort": effort_score,
            "priority": "P0" if (impact_score > 7 and effort_score < 4) else "P1"
        })

    # Step 2: Streamlitで人間が最終調整
    # （承認画面で優先度を手動変更可能）

    return sorted(tasks, key=lambda x: (x['priority'], -x['impact']))
```

## 6. Gem_05: Echo_Monitor（詳細設計）

### 6.1 役割

**AI Overviews（AIO）での自社ブランドのメンション状況を追跡**

### 6.2 実装方法（動画ベース）

**動画「11. AI Overviewsメンション・参照分析」の手法**:
```
Serp APIを用いて検索結果を取得。
AI Overviewsの回答文や参照元リンクに、
自社のサービス名が何番目に言及されているかをリスト化し、
LLMからの評価状況をモニタリングする。
```

### 6.3 コード実装

```python
def track_aio_mentions(query: str, brand_name: str) -> Dict:
    """
    Serp APIでAI Overviewsのメンション位置を追跡
    """
    # Serp API経由でGoogle検索結果を取得
    serp_result = serpapi.search({
        "q": query,
        "engine": "google",
        "google_domain": "google.co.jp",
        "gl": "jp",
        "hl": "ja"
    })

    # AI Overviewsセクションを抽出
    ai_overview = serp_result.get("ai_overview", {})
    answer_text = ai_overview.get("answer", "")
    references = ai_overview.get("references", [])

    # ブランド言及の検出
    mention_found = brand_name in answer_text
    mention_position = answer_text.find(brand_name) if mention_found else -1

    # 参照元リンクでの順位
    reference_rank = None
    for i, ref in enumerate(references):
        if brand_name.lower() in ref.get("title", "").lower():
            reference_rank = i + 1
            break

    # Citation_Master に保存
    citation = {
        "query_id": generate_query_id(),
        "query_text": query,
        "entity_name": brand_name,
        "mention_count": 1 if mention_found else 0,
        "sentiment_score": analyze_sentiment(answer_text, brand_name),
        "reference_type": "AI_Overview",
        "source_url": "google.com",
        "position_in_response": mention_position,
        "reference_rank": reference_rank
    }

    return citation
```

## 7. MCP（Model Context Protocol）統合

### 7.1 MCPとは

**動画での説明**:
```
Claudeの画面上から直接AhrefsやSerp APIを叩きに行く
MCP連携が紹介されています。
```

**公式定義** (Anthropic):
- LLMがローカルツールやリモートAPIに安全にアクセスするためのプロトコル
- Claude DesktopやClaude Code等で利用可能

### 7.2 MCP設定ファイル

**新規作成**: `config/mcp_config.json`

```json
{

      "args": ["-y", "@modelcontextprotocol/server-ahrefs"],
      "env": {
        "AHREFS_API_KEY": "${AHREFS_API_KEY}"
      }
    },
    "serpapi": {

  }

```

### 7.3 MCP経由のAPI呼び出し例

```python
# src/api/external/ahrefs_mcp_client.py

from anthropic import Anthropic

class AhrefsMCPClient:
    def __init__(self):
        self.client = Anthropic()

    def get_keyword_gap(self, target: str, competitors: List[str]) -> List[Dict]:
        """
        MCP経由でAhrefsのキーワードギャップを取得
        """
        response = self.client.messages.create(
            model="claude-sonnet-4-5",
            messages=[{
                "role": "user",
                "content": f"""
                MCPのAhrefsツールを使って、以下のキーワードギャップ分析を実行してください：

                対象ドメイン: {target}
                競合ドメイン: {', '.join(competitors)}

                競合が獲得していて対象ドメインが獲得できていないキーワードを
                トラフィックポテンシャルの高い順に20件抽出してください。
                """
            }],
            tools=[{"type": "mcp", "server": "ahrefs"}]
        )

        # Claudeが自動的にAhrefs MCPを呼び出し、結果を返す
        return response.content
```

## 8. データスキーマ（v2.1 - 簡素化版）

### 8.1 PostgreSQL統一（BigQueryは廃止）

**変更理由**:
- コスト削減（PostgreSQL: $25/月 vs BigQuery: $200/月）
- クエリコストの心配不要（PostgreSQLは定額）
- 開発の簡素化（SQLiteからの移行が容易）

### 8.2 主要テーブル

#### 8.2.1 llm_thought_log

```sql
CREATE TABLE llm_thought_log (
    id SERIAL PRIMARY KEY,
    query_id VARCHAR(36) UNIQUE NOT NULL,
    query_text TEXT NOT NULL,
    executed_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    llm_model VARCHAR(50) NOT NULL,  -- 'chatgpt-o1', 'gemini-1.5-pro' etc
```
