## 2. 画面別詳細

### 2.1 思考ログ画面（4_thought_log.py）

**目的**: ChatGPT o1の7ステップ推論プロセスを可視化

#### 主要機能

- **7ステップ推論プロセス**
  - ステップバイステップ表示（折りたたみ可能）
  - 各ステップの信頼度スコア表示
  - タイムライン形式のビジュアル

- **参照URL一覧**
  - クリック可能なリンク形式
  - 情報源の追跡が容易

- **検索クエリ候補**
  - AIが内部的に使用したクエリを可視化

- **ブランド評価**
  - 推薦されたブランドと推薦されなかったブランドを分離表示
  - センチメント別の色分け（ポジティブ/中立/ネガティブ）

#### デザイン特徴

- **グラデーションカード**: 紫系のグラデーション（#667eea → #764ba2）
- **折りたたみ可能**: 最初の3ステップは展開、残りは折りたたみ
- **タイムライン接続線**: ステップ間の流れを視覚化

#### データソース

- デモモード: `data/demo/thought_log_sample.json`
- 本番モード: データベース（LLMThoughtLogモデル）

---

### 2.2 ロードマップ画面（5_roadmap.py）

**目的**: Impact × Effort マトリクスで優先度を可視化

#### 主要機能

- **Impact × Effort マトリクス**
  - 散布図（X軸: Effort、Y軸: Impact）
  - 優先度別色分け（P0: 赤、P1: 黄、P2: 青）
  - 4象限分析（優先/計画的/隙間時間/後回し）

- **タスクリスト**
  - 優先度フィルタ（P0/P1/P2）
  - ステータスフィルタ（Pending/In_Progress/Done）
  - タイプフィルタ（Content/Technical/Analytics）

- **統計情報**
  - 優先度別分布（棒グラフ）
  - ステータス別分布（円グラフ）
  - 平均Impact/Effortスコア

#### デザイン特徴

- **優先度バッジ**: グラデーション背景で視覚的差別化
- **ステータスバッジ**: Pending（グレー）、In_Progress（青）、Done（緑）
- **タスクカード**: ホバー時のシャドウ拡大アニメーション

#### データソース

- デモモード: `data/demo/roadmap_sample.json`
- 本番モード: データベース（RoadmapRegistryモデル）

---

### 2.3 エコー監視画面（6_echo_monitor.py）

**目的**: AI Overviewsでのメンション状況をリアルタイム追跡

#### 主要機能

- **メンション数推移**
  - 過去4週間の折れ線グラフ
  - 参照順位の推移（数値が小さいほど上位）

- **センチメント分析**
  - ゲージチャート（-1.0〜1.0を0〜100に変換）
  - センチメント推移グラフ

- **最新引用一覧**
  - クエリ、LLMタイプ、順位、スコア
  - 引用コンテキストスニペット
  - 参照元URL

- **統計サマリー**
  - センチメント分布（円グラフ）
  - 参照順位分布（棒グラフ）
  - エコー成功基準の判定

#### デザイン特徴

- **エコーステータスバナー**: 成功/部分成功/失敗で色分け
- **LLMカバレッジバッジ**: アクティブ（緑）/非アクティブ（グレー）
- **センチメントゲージ**: 3段階の色分け（赤/黄/緑）

#### データソース

- デモモード: `data/demo/echo_monitor_sample.json`
- 本番モード: データベース（CitationMasterモデル）

## 3. デザインガイドライン

### 3.1 美的方向性

**コンセプト**: "Data-Driven Elegance"（データ駆動型のエレガンス）

- **目的**: 複雑なAI分析データを、美しく、直感的に理解できる形で提示
- **トーン**: プロフェッショナル × モダン × アクセシブル
- **差別化要素**: グラデーションカード + インタラクティブチャート

### 3.2 タイポグラフィ

- **フォント**: Noto Sans JP（日本語）、システムフォント（英数字）
- **ヘッダー**: 1.2rem、font-weight: 700
- **本文**: 0.95rem、line-height: 1.6
- **バッジ**: 0.85rem、font-weight: 700

### 3.3 カラーパレット

**プライマリーカラー**:
- 紫系グラデーション: `#667eea → #764ba2`（メインUI）
- 緑系グラデーション: `#11998e → #38ef7d`（成功状態）

**優先度カラー**:
- P0（最優先）: `#f5576c`（赤）
- P1（重要）: `#fee140`（黄）
- P2（通常）: `#a8edea`（水色）

**センチメントカラー**:
- ポジティブ: `#4CAF50`
- 中立: `#FF9800`
- ネガティブ: `#F44336`

### 3.4 レイアウト

- **Streamlitのレイアウト**: `st.columns`、`st.tabs`、`st.expander`
- **レスポンシブ対応**: `use_container_width=True`
- **カード間隔**: margin: 0.8rem 0

### 3.5 モーション

- **ホバーアニメーション**: box-shadowの拡大（0.2s transition）
- **ページ遷移**: Streamlitのデフォルト
- **グラフアニメーション**: Plotlyのデフォルトアニメーション

## 7. 本番環境への移行

### 7.1 データベース統合

現在はデモモードでJSONファイルを読み込んでいますが、本番環境では以下のように変更します。

#### 思考ログ画面

```python
def load_thought_log_data():
    if demo_mode:
        # デモデータ
    else:
        from src.database.connection import db
        from src.database.models_v2.llm_thought_log import LLMThoughtLog

        with db.get_session() as session:
            latest_log = session.query(LLMThoughtLog).order_by(
                LLMThoughtLog.executed_at.desc()
            ).first()

            return latest_log.to_dict() if latest_log else None
```

#### ロードマップ画面

```python
def load_roadmap_data():
    if demo_mode:
        # デモデータ
    else:
        from src.database.connection import db
        from src.database.models_v2.roadmap_registry import RoadmapRegistry

        with db.get_session() as session:
            tasks = session.query(RoadmapRegistry).all()
            return {
                'tasks': [task.to_dict() for task in tasks],
                'summary': calculate_summary(tasks)
            }
```

#### エコー監視画面

```python
def load_echo_monitor_data():
    if demo_mode:
        # デモデータ
    else:
        from src.database.connection import db
        from src.database.models_v2.citation_master import CitationMaster

        with db.get_session() as session:
            citations = session.query(CitationMaster).order_by(
                CitationMaster.created_at.desc()
            ).limit(10).all()

            return {
                'recent_citations': [c.to_dict() for c in citations],
                'current_status': calculate_status(citations),
                ...
            }
```
