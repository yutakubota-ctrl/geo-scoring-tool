#### 3. PostgreSQLセットアップ

**Supabaseでの手順**:

1. **プロジェクト作成**
   ```
   - https://supabase.com/ にサインアップ
   - 新規プロジェクト作成
   - リージョン: Northeast Asia（東京）選択
   - プラン: Pro（$25/月）選択
   ```

2. **テーブル作成スクリプト実行**
   ```bash
   cd C:\Users\yutak\OneDrive\デスクトップ\GEOスコアリングツール
   py -3 scripts/setup_postgresql.py
   ```

   **注意**: `scripts/setup_postgresql.py` は新規作成が必要

3. **接続確認**
   ```python
   # 簡易テスト
   import psycopg2
   from dotenv import load_dotenv
   import os

   load_dotenv()
   conn = psycopg2.connect(os.getenv("DATABASE_URL"))
   print("PostgreSQL接続成功！")
   conn.close()
   ```

#### 4. MCP設定

詳細は [v2.1_mcp_setup_guide.md](v2.1_mcp_setup_guide.md) を参照。

**最小限の設定**:

1. **Node.js インストール**
   ```bash
   # バージョン確認
   node --version
   # => v18.0 以上が必要

   # インストール（Windows）
   winget install OpenJS.NodeJS.LTS
   ```

2. **MCPサーバーインストール**
   ```bash
   npm install -g @modelcontextprotocol/server-ahrefs
   npm install -g @modelcontextprotocol/server-serpapi
   ```

3. **config/mcp_config.json 作成**
   ```json
   {
     "mcpServers": {
       "ahrefs": {
         "command": "npx",
         "args": ["-y", "@modelcontextprotocol/server-ahrefs"],
         "env": {
           "AHREFS_API_KEY": "${AHREFS_API_KEY}"
         }
       },
       "serpapi": {
         "command": "npx",
         "args": ["-y", "@modelcontextprotocol/server-serpapi"],
         "env": {
           "SERPAPI_API_KEY": "${SERP_API_KEY}"
         }
       }
     }
   }
   ```

## トラブルシューティング

### PostgreSQL接続エラー
```
原因: サービスアカウントの権限不足
解決: Supabaseのダッシュボードで接続情報を再確認
```

### ChatGPT o1のreasoning_content取得失敗
```
原因: モデル指定が間違っている（gpt-4oなど）
解決: model="o1-preview" を明示的に指定
```

### MCP呼び出しエラー
```
原因: Node.jsが未インストール
解決: winget install OpenJS.NodeJS.LTS
```

### API呼び出しエラー
```
原因: レート制限超過
解決: tenacityでリトライ実装、または有料プラン検討
```
