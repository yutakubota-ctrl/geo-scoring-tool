# GEOスコアリング ダッシュボード デザインレビュー v2.1

## エグゼクティブサマリー

現在のダッシュボードは**機能的には動作**しているが、**ビジュアル体験が一流とは言えない**状態。
具体的な問題は以下の3点に集約される：

1. **情報密度の問題**: 重要な情報が埋もれている
2. **視覚的階層の欠如**: 何を見るべきかが即座に分からない
3. **デザインの一貫性不足**: 各画面でトーンがバラバラ

---

## 共通問題点

### 1. デザインシステムの欠如
- 色: 各画面で異なるグラデーション
- フォント: システムフォントのみ
- 余白: 不統一

### 2. Streamlitのデフォルト依存
- `st.metric` のデザインがそのまま
- `st.dataframe` のスタイルが標準
- `st.markdown("---")` が多用されて単調

### 3. モバイル対応の考慮不足
- カラム構成がPC前提
- カードサイズが固定的

## デザイン方針

### カラーパレット（提案）
```
Primary: #0F172A (深いネイビー - 信頼性)
Secondary: #3B82F6 (鮮やかなブルー - アクション)
Accent: #10B981 (エメラルドグリーン - 成功/ポジティブ)
Warning: #F59E0B (アンバー - 注意)
Danger: #EF4444 (レッド - 警告)
Background: #F8FAFC (淡いグレー)
Surface: #FFFFFF (白)
Text Primary: #1E293B
Text Secondary: #64748B
```

### タイポグラフィ（提案）
- 見出し: **IBM Plex Sans** (クリーンでモダン、技術感)
- 本文: **Noto Sans JP** (日本語対応、読みやすい)
- 数値: **JetBrains Mono** (等幅でダッシュボードに最適)

### アニメーション（提案）
- フェードイン: 0.3s ease-in-out
- ホバー: 0.2s transform scale(1.02)
- チャート更新: 0.5s transition
