```bash

```

### コードロールバック

```bash
# 直前のコミットに戻す
git revert HEAD

# 特定のコミットまで戻す
git revert <commit-hash>

git push origin main
```

### テーマ切替フォールバック

```python
# common.py に追加
USE_AEO_THEME = os.environ.get("USE_AEO_THEME", "false").lower() == "true"

def get_active_colors():
    return COLORS_AEO if USE_AEO_THEME else COLORS
```

環境変数 `USE_AEO_THEME=false` でライトテーマに戻せる。

## リスクと対策

| リスク | 影響度 | 対策 |
|--------|--------|------|
| ダークテーマで視認性低下 | 中 | A/Bテスト、ユーザーフィードバック収集 |
| Plotlyチャートのパフォーマンス | 低 | データポイント数の制限 |
| 既存ユーザーの混乱 | 中 | 変更告知、ドキュメント更新 |
| CSS競合 | 低 | スコープ付きクラス名使用 |
