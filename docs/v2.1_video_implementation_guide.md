## 1. GA4/サーチコンソール減少要因分析

### 動画での説明
「GA4とサーチコンソールのデータをCSVで取得し、Claudeに分析させることで、トラフィック減少の要因（アルゴリズム変動、技術的問題、ページ削除等）を特定する」

### 優先度
**P2**（将来版） - MVP範囲外

### 実装時期
フェーズ3以降（Week 17〜）

### 必要なツール・API
- Google Analytics 4 API
- Google Search Console API
- Pandas（データ処理）

### データフロー
```
[Input]
GA4 CSV（過去6ヶ月のページ別セッション数）
Search Console CSV（クエリ別クリック数・表示回数）

↓

[Processing]
1. 月次比較で減少率を計算
2. 減少ページ/クエリをリスト化
3. Claudeに原因分析を依頼

↓

[Output]
{
  "減少ページTOP10": [...],
  "推定原因": "コアアップデート影響",
  "対策提案": "E-E-A-T強化コンテンツ追加"
}
```

### コード例
```python
# src/analytics/ga4_analyzer.py

import pandas as pd
from anthropic import Anthropic

class GA4Analyzer:
    def __init__(self):
        self.client = Anthropic()

    def analyze_traffic_drop(self, ga4_csv: str, gsc_csv: str) -> dict:
        """
        GA4とGSCデータからトラフィック減少要因を分析
        """
        # データ読み込み
        ga4_data = pd.read_csv(ga4_csv)
        gsc_data = pd.read_csv(gsc_csv)

        # 前月比減少率を計算
        ga4_data['decrease_rate'] = (
            (ga4_data['sessions_current'] - ga4_data['sessions_previous'])
            / ga4_data['sessions_previous'] * 100
        )

        # 減少率TOP10を抽出
        top_decreases = ga4_data.nsmallest(10, 'decrease_rate')

        # Claudeで原因分析
        prompt = f"""
        以下のページでトラフィックが大幅に減少しています。
        減少要因を推測し、3つの対策を提案してください。

        {top_decreases.to_string()}
        """

        response = self.client.messages.create(
            model="claude-sonnet-4-5",
            max_tokens=2000,
            messages=[{"role": "user", "content": prompt}]
        )

        return {
            "decreased_pages": top_decreases.to_dict('records'),
            "analysis": response.content[0].text
        }
```

### 注意点
- GA4の仕様変更に注意（Universal Analyticsとは異なる）
- サーチコンソールのAPIは1日1000リクエストまで制限あり

class AhrefsAnalyzer:
    def __init__(self, mcp_client):
        self.mcp = mcp_client

    def analyze_ranking_drop(self, domain: str, period_days: int = 90) -> dict:
        """
        Ahrefs MCPで順位低下要因を分析
        """
        # MCP経由でAhrefsデータ取得
        organic_keywords = self.mcp.get_organic_keywords(
            target=domain,
            limit=1000,
            date_from=f"-{period_days}days"
        )

        # 順位低下キーワードをフィルタ
        dropped_keywords = [
            kw for kw in organic_keywords
            if kw['position_diff'] < -5  # 5位以上ダウン
        ]

        # Claude分析
        analysis = self.claude_analyze(dropped_keywords)

        return {
            "dropped_keywords_count": len(dropped_keywords),
            "top_losers": dropped_keywords[:10],
            "root_cause": analysis["原因"],
            "action_items": analysis["対策"]
        }

## 4. GRC順位差分分析

### 動画での説明
「GRC（検索順位チェックツール）のデータをCSV出力し、自社と競合のトップ10獲得数を比較。カテゴリ別（製品名キーワード、一般キーワード等）に勝敗を可視化」

### 優先度
**P0（最優先）** - MVP範囲内

### 実装時期
Week 7-8（Gem_02実装時）

### 必要なツール・API
- GRC（Windows版）または Serpstat/Ahrefs Rank Tracker
- CSV出力機能

### データフロー
```
[Input]
GRC CSV（keyword, own_rank, competitor_rank）

↓

[Processing]
1. トップ10以内獲得数を集計
2. カテゴリ別に分類（製品名、一般キーワード等）
3. 勝敗マトリクス作成

↓

[Output]
{
  "自社TOP10獲得数": 45,
  "競合TOP10獲得数": 72,
  "ギャップ": -27,
  "負けているカテゴリ": "一般キーワード",
  "具体的敗北キーワード": [...]
}
```

### コード例
```python
# src/analytics/grc_analyzer.py

import pandas as pd

class GRCAnalyzer:
    def analyze_rank_gap(self, grc_csv: str, own_domain: str, competitor_domain: str) -> dict:
        """
        GRCの順位データから自社・競合の差分を分析
        """
        df = pd.read_csv(grc_csv, encoding='shift_jis')  # GRCはShift_JIS

        # 自社のトップ10獲得数
        own_top10 = df[(df['domain'] == own_domain) & (df['rank'] <= 10)]

        # 競合のトップ10獲得数
        comp_top10 = df[(df['domain'] == competitor_domain) & (df['rank'] <= 10)]

        # カテゴリ別集計
        category_analysis = self.categorize_keywords(own_top10, comp_top10)

        # 負けているキーワード抽出
        losing_keywords = df[
            (df[f'{own_domain}_rank'] > 10) &
            (df[f'{competitor_domain}_rank'] <= 10)
        ]['keyword'].tolist()

        return {
            "own_top10_count": len(own_top10),
            "competitor_top10_count": len(comp_top10),
            "gap": len(comp_top10) - len(own_top10),
            "category_breakdown": category_analysis,
            "losing_keywords": losing_keywords[:20]  # 上位20件
        }

    def categorize_keywords(self, own_df, comp_df) -> dict:
        """
        キーワードをカテゴリ分類
        """
        categories = {
            "製品名": ["製品名", "サービス名"],
            "一般キーワード": ["おすすめ", "比較", "ランキング"],
            "課題キーワード": ["悩み", "解決", "方法"]
        }

        results = {}
        for category, patterns in categories.items():
            own_count = sum(own_df['keyword'].str.contains('|'.join(patterns)))
            comp_count = sum(comp_df['keyword'].str.contains('|'.join(patterns)))
            results[category] = {
                "own": own_count,
                "competitor": comp_count,
                "gap": comp_count - own_count
            }

        return results
```

### 注意点
- GRCのCSVは**Shift_JIS**エンコーディング（UTF-8ではない）
- Google Search Consoleの順位データとは微妙に異なる場合がある

## 5. Ahrefsキーワードギャップ

### 動画での説明
「Ahrefsのキーワードギャップ機能を使い、競合が獲得していて自社が獲得できていないキーワード群を抽出。トラフィックポテンシャルの高い順に優先順位付け」

### 優先度
**P0（最優先）** - MVP範囲内

### 実装時期
Week 7-8（Gem_02実装時）

### 必要なツール・API
- Ahrefs API（または MCP Server推奨）

### データフロー
```
[Input]
自社ドメイン: example.com
競合ドメイン: competitor.com

↓

[Processing - MCP経由]
1. Ahrefs MCPでキーワードギャップ取得
2. トラフィックポテンシャル計算
3. 難易度（KD）でフィルタ

↓

[Output]
{
  "gap_keywords_count": 1247,
  "total_traffic_potential": 35000,
  "top_opportunities": [
    {
      "keyword": "マーケティングツール 比較",
      "volume": 2400,
      "kd": 35,
      "traffic_potential": 960
    },
    ...
  ]
}
```

### コード例
```python
# src/analytics/keyword_gap_analyzer.py

from anthropic import Anthropic

class KeywordGapAnalyzer:
    def __init__(self):
        self.client = Anthropic()

    def analyze_gap(self, own_domain: str, competitor_domains: list) -> dict:
        """
        MCP経由でAhrefsキーワードギャップを分析
        """
        # Claudeに依頼（MCPツールを自動使用）
        response = self.client.messages.create(
            model="claude-sonnet-4-5",
            max_tokens=4000,
            messages=[{
                "role": "user",
                "content": f"""
                MCPのAhrefsツールを使って、以下のキーワードギャップ分析を実行してください：

                対象ドメイン: {own_domain}
                競合ドメイン: {', '.join(competitor_domains)}

                以下の条件でフィルタしてください：
                - 競合が獲得していて対象ドメインが獲得できていないキーワード
                - 検索ボリューム: 100以上
                - Keyword Difficulty: 50以下（獲得可能性が高い）
                - トラフィックポテンシャルの高い順に20件

                結果をJSON形式で返してください。
                """
            }]
        )

        # Claudeが返したJSON結果をパース
        gap_data = self.parse_mcp_response(response.content[0].text)

        # 追加処理：トラフィックポテンシャル計算
        for kw in gap_data['keywords']:
            kw['traffic_potential'] = kw['volume'] * kw['ctr_estimate']

        # ソート
        gap_data['keywords'].sort(key=lambda x: x['traffic_potential'], reverse=True)

        return {
            "gap_keywords_count": len(gap_data['keywords']),
            "total_traffic_potential": sum(k['traffic_potential'] for k in gap_data['keywords']),
            "top_opportunities": gap_data['keywords'][:20]
        }
```

### 注意点
- Ahrefs APIは呼び出し回数制限あり（プランによる）
- MCP経由の場合、Claudeが自動的にリトライするため安全
- Keyword Difficulty（KD）は参考値（実際の競合性とは異なる場合あり）

## 6. ページ要素比較分析

### 動画での説明
「自社と競合のページを比較し、料金表、FAQ、口コミ、導入実績等の要素の有無を『マルバツ表』で可視化。不足要素を特定する」

### 優先度
**P1**（重要） - MVP範囲内

### 実装時期
Week 9-10

### 必要なツール・API
- Claude API（Webページ解析）
- Jina Reader API（オプション、HTML→Markdown変換）

### データフロー
```
[Input]
自社URL: https://example.com/pricing
競合URLs: [competitor1.com/pricing, competitor2.com/pricing]

↓

[Processing]
1. 各URLのコンテンツ取得
2. Claudeで要素検出（料金表、FAQ、口コミ等）
3. マルバツ表作成

↓

[Output - Markdown Table]
| 要素 | 自社 | 競合A | 競合B |
|------|------|-------|-------|
| 料金表 | ○ | ○ | ○ |
| 導入実績 | ✕ | ○ | ○ | ← 不足！
| FAQ | ○ | ✕ | ○ |
```

### コード例
```python
# src/analytics/page_element_analyzer.py

import httpx
from anthropic import Anthropic

class PageElementAnalyzer:
    def __init__(self):
        self.client = Anthropic()

    def compare_page_elements(
        self,
        own_url: str,
        competitor_urls: list,
        elements: list = None
    ) -> dict:
        """
        ページ内要素を比較分析
        """
        if elements is None:
            elements = [
                "料金表",
                "導入実績・導入企業ロゴ",
                "FAQ（よくある質問）",
                "口コミ・レビュー",
                "無料トライアルボタン",
                "比較表（他社との違い）",
                "動画デモ",
                "お客様の声"
            ]

        all_urls = [own_url] + competitor_urls
        results = {}

        for url in all_urls:
            # ページ取得
            content = self.fetch_page(url)

            # Claude分析
            analysis = self.analyze_elements(content, elements)
            results[url] = analysis

        # マルバツ表生成
        comparison_table = self.generate_comparison_table(results, elements)

        # 不足要素抽出
        missing_elements = self.identify_gaps(results, own_url, competitor_urls)

        return {
            "comparison_table": comparison_table,
            "missing_elements": missing_elements,
            "recommendations": self.generate_recommendations(missing_elements)
        }

    def analyze_elements(self, content: str, elements: list) -> dict:
        """
        Claudeでページ要素の有無を判定
        """
        prompt = f"""
        以下のWebページコンテンツを分析し、指定された要素が含まれているか判定してください。

        【チェック項目】
        {chr(10).join(f'- {elem}' for elem in elements)}

        【コンテンツ】
        {content[:4000]}  # 最初の4000文字

        各要素について、「あり」「なし」「部分的」で判定し、JSON形式で返してください。
        """

        response = self.client.messages.create(
            model="claude-sonnet-4-5",
            max_tokens=1000,
            messages=[{"role": "user", "content": prompt}]
        )

        # JSON解析
        return self.parse_json_response(response.content[0].text)

    def identify_gaps(self, results: dict, own_url: str, competitor_urls: list) -> list:
        """
        自社に不足していて競合にある要素を特定
        """
        own_elements = results[own_url]
        gaps = []

        for element in own_elements.keys():
            # 自社にない
            if own_elements[element] == "なし":
                # 競合の半数以上が持っている
                comp_count = sum(
                    1 for comp_url in competitor_urls
                    if results[comp_url].get(element) == "あり"
                )
                if comp_count >= len(competitor_urls) / 2:
                    gaps.append(element)

        return gaps
```

## 7. Ahrefs被リンク差分分析

### 動画での説明
「Ahrefsの被リンク分析で、競合が獲得していて自社が獲得できていないリンク元ドメインを特定。DR（ドメインレーティング）の高いサイトを優先的にリストアップ」

↓

[Processing]

### コード例
```python
# src/analytics/backlink_gap_analyzer.py

class BacklinkGapAnalyzer:
    def analyze_backlink_gap(self, own_domain: str, competitor_domain: str) -> dict:
        """
        被リンクギャップ分析
        """
        # Ahrefs MCPで競合の被リンク取得
        competitor_backlinks = self.mcp.get_backlinks(
            target=competitor_domain,
            mode="domain",
            limit=500,
            order_by="domain_rating:desc"
        )

        # 自社の被リンク取得
        own_backlinks = self.mcp.get_backlinks(
            target=own_domain,
            mode="domain",
            limit=500
        )

        # 差分抽出
        own_domains = set(bl['domain'] for bl in own_backlinks)
        gap_backlinks = [
            bl for bl in competitor_backlinks
            if bl['domain'] not in own_domains and bl['domain_rating'] >= 50
        ]

        # 獲得難易度推定
        for bl in gap_backlinks:
            bl['acquisition_difficulty'] = self.estimate_difficulty(bl)

        return {
            "backlink_gap_count": len(gap_backlinks),
            "high_value_targets": gap_backlinks[:20]
        }
```

### 完全実装コード
```python
# src/agents/gem_01_intelligence.py

from openai import OpenAI
from anthropic import Anthropic
import json
from typing import Dict, List

class Gem01Intelligence:
    def __init__(self):
        self.openai_client = OpenAI()
        self.claude_client = Anthropic()

    def analyze_chatgpt_thinking(self, query: str) -> Dict:
        """
        ChatGPT o1の思考プロセスを解析

        Args:
            query: 検索クエリ（例: "マーケティングツール おすすめ"）

        Returns:
            思考トレース、参照URL、推論プロセス
        """
        # Step 1: ChatGPT o1 に検索クエリを投げる
        print(f"[Gem_01] ChatGPT o1でクエリ分析中: {query}")

        chatgpt_response = self.openai_client.chat.completions.create(
            model="o1-preview",  # または o1-mini
            messages=[{
                "role": "user",
                "content": f"""
                以下の検索クエリについて、おすすめのツール・サービスを3つ挙げてください：

                "{query}"

                各ツールについて、以下を明記してください：
                - なぜそのツールを選んだか
                - どの情報源を参考にしたか
                - どのような基準で評価したか
                """
            }]
        )

        # Step 2: 思考プロセス（reasoning_content）を抽出
        thinking_steps = chatgpt_response.choices[0].message.reasoning_content
        final_answer = chatgpt_response.choices[0].message.content

        print(f"[Gem_01] 思考ステップ取得完了（{len(thinking_steps)} 文字）")

        # Step 3: Claudeで思考プロセスを構造化
        analysis = self.analyze_with_claude(thinking_steps, final_answer, query)

        # Step 4: PostgreSQLに保存
        thought_log = self.save_to_db(query, analysis)

        return thought_log

    def analyze_with_claude(self, thinking: str, answer: str, query: str) -> Dict:
        """
        Claudeで思考プロセスを構造化
        """
        prompt = f"""
        以下はChatGPT o1の推論プロセスです。

        【検索クエリ】
        {query}

        【ChatGPTの思考プロセス】
        {thinking}

        【ChatGPTの最終回答】
        {answer}

        この推論プロセスを分析し、以下をJSON形式で抽出してください：

        1. **7ステップの分解**:
           - step_1: 候補ブランドの列挙
           - step_2: 公式サイトの確認
           - step_3: 第三者レビューサイトの参照
           - step_4: 公的機関の確認
           - step_5: 料金・機能比較
           - step_6: 口コミ・評判の確認
           - step_7: 最終判断

        2. **検索クエリ候補**: ChatGPTが内部で使用したと推測される検索クエリ

        3. **参照URL**: 言及されたドメイン・サイト

        4. **最終推論**: なぜそのブランドを選んだか（1文）

        JSON形式で返してください。
        """

        response = self.claude_client.messages.create(
            model="claude-sonnet-4-5",
            max_tokens=4000,
            messages=[{"role": "user", "content": prompt}]
        )

        # JSON解析
        analysis_text = response.content[0].text

        # JSONブロック抽出（```json ... ``` の部分）
        if "```json" in analysis_text:
            json_start = analysis_text.find("```json") + 7
            json_end = analysis_text.find("```", json_start)
            json_str = analysis_text[json_start:json_end].strip()
        else:
            json_str = analysis_text

        return json.loads(json_str)

    def save_to_db(self, query: str, analysis: Dict) -> Dict:
        """
        PostgreSQLのllm_thought_logテーブルに保存
        """
        from src.database.repository import ThoughtLogRepository

        repo = ThoughtLogRepository()

        thought_log = {
            "query_id": self.generate_query_id(),
            "query_text": query,
            "llm_model": "ChatGPT o1-preview",
            "thought_trace": analysis.get("7ステップの分解", {}),
            "search_queries_used": analysis.get("検索クエリ候補", []),
            "selected_urls": analysis.get("参照URL", []),
            "final_reasoning": analysis.get("最終推論", ""),
            "analyzed_at": "2026-04-09T12:00:00Z"
        }

        repo.save(thought_log)

        return thought_log

    def generate_query_id(self) -> str:
        """
        クエリIDを生成（例: q_20260409_001）
        """
        from datetime import datetime
        timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
        return f"q_{timestamp}"
```

## 11. AI Overviewsメンション分析

### 動画での説明
「Serp APIを使い、Google検索結果のAI Overviews（AIO）セクションを取得。自社ブランドが何番目に言及されているかを追跡」

### 優先度
**P0（最優先）** - MVP範囲内

### 実装時期
Week 5-6（Gem_05実装）

### 必要なツール・API
- Serp API

### データフロー
```
[Input]
クエリ: "マーケティングツール おすすめ"
ブランド名: "HubSpot"

↓

[Processing]
1. Serp APIで検索結果取得
2. AI Overviewsセクション抽出
3. ブランド言及位置を検出

↓

[Output - Citation_Master に保存]
{
  "query_text": "マーケティングツール おすすめ",
  "entity_name": "HubSpot",
  "mention_count": 1,
  "position_in_response": 234,  # 回答文の234文字目
  "reference_rank": 2,  # 参照リンクの2番目
  "sentiment_score": 8.5
}
```

### 完全実装コード
```python
# src/agents/gem_05_echo.py

from serpapi import GoogleSearch
from anthropic import Anthropic
from typing import Dict

class Gem05EchoMonitor:
    def __init__(self, serp_api_key: str):
        self.serp_api_key = serp_api_key
        self.claude_client = Anthropic()

    def track_aio_mentions(self, query: str, brand_name: str) -> Dict:
        """
        AI Overviewsでのブランドメンション追跡

        Args:
            query: 検索クエリ
            brand_name: 追跡対象ブランド名

        Returns:
            Citation情報
        """
        # Step 1: Serp APIで検索結果取得
        search_params = {
            "q": query,
            "engine": "google",
            "google_domain": "google.co.jp",
            "gl": "jp",
            "hl": "ja",
            "api_key": self.serp_api_key
        }

        search = GoogleSearch(search_params)
        results = search.get_dict()

        # Step 2: AI Overviewsセクション抽出
        ai_overview = results.get("ai_overview", {})

        if not ai_overview:
            print(f"[Gem_05] AI Overviews未対応クエリ: {query}")
            return None

        answer_text = ai_overview.get("answer", "")
        references = ai_overview.get("references", [])

        # Step 3: ブランド言及検出
        mention_found = brand_name in answer_text
        mention_position = answer_text.find(brand_name) if mention_found else -1

        # Step 4: 参照リンク内での順位
        reference_rank = None
        for i, ref in enumerate(references):
            ref_title = ref.get("title", "")
            ref_url = ref.get("link", "")
            if brand_name.lower() in ref_title.lower() or brand_name.lower() in ref_url.lower():
                reference_rank = i + 1
                break

        # Step 5: センチメント分析（Claudeで）
        sentiment_score = self.analyze_sentiment(answer_text, brand_name)

        # Step 6: Citation_Masterに保存
        citation = {
            "query_id": self.generate_query_id(),
            "query_text": query,
            "entity_name": brand_name,
            "mention_count": 1 if mention_found else 0,
            "sentiment_score": sentiment_score,
            "reference_type": "AI_Overview",
            "source_url": "google.com",
            "position_in_response": mention_position,
            "reference_rank": reference_rank,
            "tracked_at": self.get_timestamp()
        }

        self.save_to_db(citation)

        return citation

    def analyze_sentiment(self, answer_text: str, brand_name: str) -> float:
        """
        Claudeでブランドへのセンチメント分析
        """
        if brand_name not in answer_text:
            return 0.0

        # ブランド言及箇所の前後100文字を抽出
        mention_pos = answer_text.find(brand_name)
        context_start = max(0, mention_pos - 100)
        context_end = min(len(answer_text), mention_pos + len(brand_name) + 100)
        context = answer_text[context_start:context_end]

        # Claudeでセンチメント判定
        prompt = f"""
        以下のテキストで「{brand_name}」がどのように言及されているか、
        センチメントスコアを0〜10で評価してください。

        0: 非常にネガティブ
        5: 中立
        10: 非常にポジティブ

        【テキスト】
        {context}

        スコアのみを数値で返してください（例: 7.5）
        """

        response = self.claude_client.messages.create(
            model="claude-haiku-4-5",  # 高速・安価なHaikuを使用
            max_tokens=10,
            messages=[{"role": "user", "content": prompt}]
        )

        try:
            score = float(response.content[0].text.strip())
            return min(10.0, max(0.0, score))  # 0-10の範囲に制限
        except ValueError:
            return 5.0  # パース失敗時は中立
```

### 注意点
- AI Overviewsは全クエリで表示されるわけではない（対応率60%程度）
- 日本語クエリでは非表示が多い（英語の方が高確率）
- Serp APIのプランによって月間リクエスト数制限あり

## 12. サーチジャーニー分析

### 動画での説明
「ユーザーが最初に検索するクエリ（情報検索）から、最終的に購入・比較するクエリ（トランザクショナル）までのジャーニーをマッピング。各段階で上位表示すべきキーワードを特定」

### 優先度
**P1**（重要） - MVP一部実装

### 実装時期
Week 9-10

### 必要なツール・API
- Ahrefs API（キーワード調査）
- Claude API（ジャーニーマッピング）

### データフロー
```
[Input]
基点キーワード: "マーケティングツール"

↓

[Processing]
1. Ahrefsで関連キーワード1000件取得
2. Claudeで意図分類（情報 vs 比較 vs 購入）
3. ジャーニーステージにマッピング

↓

[Output]
{
  "awareness_stage": ["マーケティングツール とは", "マーケティング 種類"],
  "consideration_stage": ["マーケティングツール 比較", "HubSpot Marketo 違い"],
  "decision_stage": ["HubSpot 料金", "HubSpot 無料トライアル"]
}
```

### コード例
```python
# src/analytics/search_journey_analyzer.py

class SearchJourneyAnalyzer:
    def map_journey(self, seed_keyword: str) -> Dict:
        """
        サーチジャーニーをマッピング
        """
        # Step 1: Ahrefsで関連キーワード取得
        related_keywords = self.ahrefs_mcp.get_keyword_ideas(
            seed=seed_keyword,
            limit=1000
        )

        # Step 2: Claudeで意図分類
        journey_map = self.classify_intent(related_keywords)

        return journey_map

    def classify_intent(self, keywords: List[str]) -> Dict:
        """
        キーワードを検索意図で分類
        """
        prompt = f"""
        以下のキーワードを検索意図で分類してください：

        【分類基準】
        - Awareness（認知・情報収集）: 「とは」「種類」「メリット」等
        - Consideration（比較検討）: 「比較」「おすすめ」「ランキング」等
        - Decision（購入決定）: 「料金」「無料」「導入」等

        【キーワード】
        {chr(10).join(keywords[:100])}  # 最初の100件

        JSON形式で返してください。
        """

        response = self.claude_client.messages.create(
            model="claude-sonnet-4-5",
            max_tokens=3000,
            messages=[{"role": "user", "content": prompt}]
        )

        return self.parse_json_response(response.content[0].text)
```
