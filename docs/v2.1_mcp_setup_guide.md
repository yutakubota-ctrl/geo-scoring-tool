## 1. MCPとは

### 1.1 概要

**MCP（Model Context Protocol）**は、Anthropicが開発した、LLMがローカルツールやリモートAPIに安全にアクセスするためのオープンプロトコルです。

### 1.2 従来のAPI連携との違い

| 項目 | 従来のAPI連携 | MCP統合 |
|------|-------------|---------|
| **実装方法** | Pythonコードで直接API呼び出し | LLMが自律的にツール呼び出し |
| **エラーハンドリング** | 開発者が実装 | LLMが自動リトライ |
| **柔軟性** | 固定パラメータ | LLMが文脈に応じて動的調整 |
| **保守性** | APIアップデートで要修正 | MCPサーバー更新のみ |

### 1.3 v2.1での活用目的

1. **Ahrefs API連携の簡素化**
   - キーワードギャップ、被リンク分析をLLMが自律実行
   - パラメータの最適化を人間が意識不要

2. **Serp API連携の自動化**
   - AI Overviews取得をLLMが判断して実行
   - 検索クエリのバリエーション生成も自動

3. **将来のAPI拡張の容易化**
   - 新しいAPIもMCPサーバーとして追加するだけ
   - エージェントコードの変更不要

#### index.js（簡略版）

```javascript
#!/usr/bin/env node
import { Server } from '@modelcontextprotocol/sdk/server/index.js';
import { StdioServerTransport } from '@modelcontextprotocol/sdk/server/stdio.js';
import axios from 'axios';

const SCREAMING_FROG_API = 'https://api.screamingfrog.co.uk';
const API_KEY = process.env.SCREAMING_FROG_API_KEY;

const server = new Server(
  {
    name: 'mcp-server-screaming-frog',
    version: '1.0.0',
  },
  {
    capabilities: {
      tools: {},
    },
  }
);

// ツール定義: サイトクロール
server.setRequestHandler('tools/list', async () => {
  return {
    tools: [
      {
        name: 'crawl_site',
        description: 'Crawl a website and return technical SEO issues',
        inputSchema: {
          type: 'object',
          properties: {
            url: {
              type: 'string',
              description: 'Website URL to crawl',
            },
            max_pages: {
              type: 'number',
              description: 'Maximum pages to crawl (default: 500)',
            },
          },
          required: ['url'],
        },
      },
    ],
  };
});

// ツール実行
server.setRequestHandler('tools/call', async (request) => {
  if (request.params.name === 'crawl_site') {
    const { url, max_pages = 500 } = request.params.arguments;

    // Screaming Frog Cloud API 呼び出し
    const response = await axios.post(`${SCREAMING_FROG_API}/crawl`, {
      url,
      max_pages,
    }, {
      headers: {
        'Authorization': `Bearer ${API_KEY}`,
      },
    });

    const crawl_id = response.data.crawl_id;

    // クロール完了を待つ（簡略版）
    await new Promise(resolve => setTimeout(resolve, 30000)); // 30秒待機

    // 結果取得
    const results = await axios.get(`${SCREAMING_FROG_API}/crawl/${crawl_id}/results`, {
      headers: { 'Authorization': `Bearer ${API_KEY}` },
    });

    return {
      content: [{
        type: 'text',
        text: JSON.stringify(results.data, null, 2),
      }],
    };
  }
});

// サーバー起動
const transport = new StdioServerTransport();
await server.connect(transport);
```

## 7. Python統合

### 7.1 MCPクライアントの実装

```python
# src/api/mcp/mcp_client.py

from anthropic import Anthropic
from typing import Dict, List, Any
import json

class MCPClient:
    """
    MCP統合クライアント
    Claudeを介してMCPサーバーにアクセス
    """

    def __init__(self, api_key: str = None):
        self.client = Anthropic(api_key=api_key)

    def call_tool(
        self,
        tool_name: str,
        server_name: str,
        arguments: Dict[str, Any],
        model: str = "claude-sonnet-4-5"
    ) -> Dict:
        """
        MCPツールを呼び出し

        Args:
            tool_name: ツール名（例: "get_keyword_gap"）
            server_name: MCPサーバー名（例: "ahrefs"）
            arguments: ツール引数
            model: 使用するClaudeモデル

        Returns:
            ツール実行結果
        """
        # Claudeにツール実行を依頼
        prompt = self._build_tool_prompt(tool_name, server_name, arguments)

        response = self.client.messages.create(
            model=model,
            max_tokens=4096,
            messages=[{"role": "user", "content": prompt}]
        )

        # 結果をパース
        result_text = response.content[0].text
        return self._parse_tool_result(result_text)

    def _build_tool_prompt(
        self,
        tool_name: str,
        server_name: str,
        arguments: Dict[str, Any]
    ) -> str:
        """
        MCPツール呼び出し用のプロンプトを構築
        """
        args_str = json.dumps(arguments, ensure_ascii=False, indent=2)

        prompt = f"""
        MCPの{server_name}サーバーを使用して、{tool_name}ツールを実行してください。

        引数:
        {args_str}

        実行結果をJSON形式で返してください。
        """

        return prompt

    def _parse_tool_result(self, text: str) -> Dict:
        """
        Claude応答からJSON結果を抽出
        """
        # JSONブロック抽出
        if "```json" in text:
            json_start = text.find("```json") + 7
            json_end = text.find("```", json_start)
            json_str = text[json_start:json_end].strip()
        else:
            # JSON部分を推測
            json_str = text.strip()

        try:
            return json.loads(json_str)
        except json.JSONDecodeError:
            # パース失敗時はテキストをそのまま返す
            return {"raw_response": text}
```

### 7.2 Ahrefs MCP ラッパー

```python
# src/api/mcp/ahrefs_mcp_wrapper.py

from .mcp_client import MCPClient
from typing import List, Dict

class AhrefsMCPWrapper:
    """
    Ahrefs MCP ラッパー
    """

    def __init__(self):
        self.mcp = MCPClient()

    def get_keyword_gap(
        self,
        target_domain: str,
        competitor_domains: List[str],
        limit: int = 20
    ) -> Dict:
        """
        キーワードギャップ取得

        Args:
            target_domain: 対象ドメイン
            competitor_domains: 競合ドメインリスト
            limit: 取得件数

        Returns:
            キーワードギャップデータ
        """
        arguments = {
            "target": target_domain,
            "competitors": competitor_domains,
            "limit": limit,
            "mode": "missing",  # 競合が持っていて自社が持っていない
            "order_by": "traffic_potential",
            "order": "desc"
        }

        result = self.mcp.call_tool(
            tool_name="get_keyword_gap",
            server_name="ahrefs",
            arguments=arguments
        )

        return result

    def get_backlinks(
        self,
        target_domain: str,
        limit: int = 100,
        min_dr: int = 50
    ) -> List[Dict]:
        """
        被リンク取得

        Args:
            target_domain: 対象ドメイン
            limit: 取得件数
            min_dr: 最小DR

        Returns:
            被リンクリスト
        """
        arguments = {
            "target": target_domain,
            "mode": "domain",
            "limit": limit,
            "order_by": "domain_rating",
            "order": "desc"
        }

        result = self.mcp.call_tool(
            tool_name="get_backlinks",
            server_name="ahrefs",
            arguments=arguments
        )

        # DR フィルタ
        backlinks = result.get("backlinks", [])
        filtered = [bl for bl in backlinks if bl.get("domain_rating", 0) >= min_dr]

        return filtered
```

## 8. トラブルシューティング

### 8.1 MCPサーバーが起動しない

**症状**:
```
Error: MCP server 'ahrefs' failed to start
```

**原因と対処**:

1. **Node.jsが未インストール**
   ```bash
   # Node.jsバージョン確認
   node --version
   # => v18.0.0 以上が必要

   # インストール（Windows）
   winget install OpenJS.NodeJS.LTS
   ```

2. **APIキーが設定されていない**
   ```bash
   # .env ファイルを確認
   cat .env | grep AHREFS_API_KEY
   # => AHREFS_API_KEY=your_key_here が必要
   ```

3. **MCPサーバーパッケージが未インストール**
   ```bash
   npm list -g @modelcontextprotocol/server-ahrefs
   # => 見つからない場合はインストール
   npm install -g @modelcontextprotocol/server-ahrefs
   ```

### 8.2 MCP呼び出しがタイムアウトする

**症状**:
```
TimeoutError: MCP tool call exceeded 30s
```

**原因と対処**:

1. **APIレート制限**
   - Ahrefs/Serp APIのレート制限に達している
   - 解決: 有料プランへのアップグレード

2. **タイムアウト設定が短い**
   ```python
   # タイムアウトを延長
   response = self.client.messages.create(
       model="claude-sonnet-4-5",
       max_tokens=4096,
       timeout=120,  # 120秒に延長
       messages=[...]
   )
   ```

### 8.3 MCP結果が期待と異なる

**症状**:
Claude がMCPを使わず、想像で回答してしまう

**原因と対処**:

1. **プロンプトが曖昧**
   ```python
   # ❌ 悪い例
   "Ahrefsでキーワードギャップを調べて"

   # ✅ 良い例
   "MCPのAhrefsツールを使って、get_keyword_gapを実行してください。
   target: example.com, competitors: [competitor.com]"
   ```

2. **MCPサーバーが登録されていない**
   ```bash
   # Claude Code の設定ファイルを確認
   cat ~/.config/claude-code/config.json
   # => mcpServers に ahrefs が含まれているか確認

## 10. パフォーマンス最適化

### 10.1 キャッシング

```python
# src/api/mcp/cache_wrapper.py

import json
from pathlib import Path
from datetime import datetime, timedelta

class MCPCacheWrapper:
    def __init__(self, cache_dir: str = ".cache/mcp"):
        self.cache_dir = Path(cache_dir)
        self.cache_dir.mkdir(parents=True, exist_ok=True)

    def get_cached(self, key: str, ttl_hours: int = 24):
        """
        キャッシュ取得
        """
        cache_file = self.cache_dir / f"{key}.json"

        if not cache_file.exists():
            return None

        # TTLチェック
        file_time = datetime.fromtimestamp(cache_file.stat().st_mtime)
        if datetime.now() - file_time > timedelta(hours=ttl_hours):
            return None  # 期限切れ

        with open(cache_file, 'r', encoding='utf-8') as f:
            return json.load(f)

    def set_cache(self, key: str, data: dict):
        """
        キャッシュ保存
        """
        cache_file = self.cache_dir / f"{key}.json"

        with open(cache_file, 'w', encoding='utf-8') as f:
            json.dump(data, f, ensure_ascii=False, indent=2)
```
