GEOスコアリングとは

GEO（Generative Engine Optimization）スコアリングは、AI検索エンジン（Gemini、ChatGPT、Perplexity等）の 応答におけるブランドの可視性と評価を定量化する指標です。

従来のSEOが検索結果の順位を最適化するのに対し、
GEOはAIが生成する回答の中でブランドがどのように言及・推奨されるかを最適化します。

総合スコア（0〜100点）

総合スコアは以下4つの指標の合計で算出されます：

10点
認知
30点
推奨度
20点
ポジション
40点
正確性
総合スコア = 認知(0-10) + 推奨度(-10〜30) + ポジション(0-20) + 正確性(0-40)
👁️

1. 認知スコア（Visibility）

0点 または 10点

AIの応答文中にブランド名が明示的に言及されているかを評価します。

スコア 条件 例
10点 ブランド名が1回以上言及 「Salesforceは最も人気のあるCRMです」
0点 ブランド名が一切言及されていない 「CRMツールには様々な選択肢があります」

判定ロジック: ブランド名の完全一致または部分一致（大文字小文字を区別しない）で検索。 略称や別名も考慮（例: Salesforce → SF, セールスフォース）

💜

2. 推奨度スコア（Sentiment）

-10点 〜 30点

ブランドがどのようなトーンで言及されているかを感情分析で評価します。

スコア 評価 典型的な表現
30点 強く肯定的 「最もおすすめ」「業界最高」「圧倒的な」「絶対に使うべき」
20点 やや肯定的 「人気がある」「信頼性が高い」「多くの企業が採用」
10点 中立的 「〜という選択肢がある」「〜も検討できます」
0点 やや否定的 「コストが高い」「学習曲線が急」「小規模には不向き」
-10点 強く否定的 「おすすめしない」「問題が多い」「避けるべき」

判定ロジック: AIが文脈を分析し、ブランドに対する感情的なトーンを5段階で評価。 比較表現（「〜より優れている」）や推奨表現（「おすすめです」）を重視。

📍

3. ポジションスコア（Positioning）

0点 〜 20点

応答文の中でどの位置に言及されているかを評価します。 一般的に、最初に言及されるブランドほど印象に残りやすいとされています。

スコア 位置 説明
20点 最優先・最初 リストの1番目、または「最もおすすめは〜」と最初に言及
15点 上位 リストの2〜3番目、または序盤のセクションで言及
10点 中位 リストの中間、または本文の中盤で言及
5点 下位 リストの後半、または補足的な位置で言及
0点 言及なし ブランドが言及されていない場合

判定ロジック: ブランドの初出位置を文字数または段落番号で特定。 リスト形式の場合は番号を、文章形式の場合は相対的な位置（前半/中盤/後半）を評価。

✓

4. 正確性スコア（Accuracy）

0点 〜 40点

ブランドに関する情報が事実に基づいて正確かを評価します。 誤情報の拡散はブランドイメージを損なうため、最も配点が高い指標です。

スコア 評価 チェック項目
40点 完全に正確 すべての情報（機能、価格、特徴）が最新かつ正確
30点 概ね正確 主要な情報は正確だが、細部に古い情報あり
20点 一部不正確 価格や機能に一部誤りがあるが、重大ではない
10点 多くが不正確 複数の重要な情報に誤りがある
0点 重大な誤情報 ブランドの根本的な特徴や存在を誤認している

判定ロジック: 参照情報（公式サイト、プレスリリース等）との照合。 以下の項目を重点的にチェック：

  • 価格・料金プラン
  • 主要機能・特徴
  • 対応プラットフォーム
  • 企業情報（設立年、本社所在地等）
  • 最新のアップデート・新機能

⚠️ 注意: 正確性評価には「参照情報」の入力を推奨します。 参照情報がない場合は、AIの一般知識に基づいて評価されます。

スコアの解釈ガイド

80-100
優秀

AIがブランドを積極的に推奨している状態

最優先で言及され、肯定的な文脈で紹介されています。GEO施策が効果を発揮しています。

60-79
良好

競合と同等以上の認知を獲得

ブランドは認知されていますが、さらなる最適化の余地があります。推奨度や位置の改善を検討してください。

40-59
要改善

認知はあるが推奨されていない

ブランドは言及されていますが、中立的または下位の扱いです。コンテンツ戦略の見直しが必要です。

0-39
要注意

AIに認知されていない、または否定的

ブランドが言及されないか、否定的な文脈で言及されています。早急なGEO施策が必要です。

GEO改善のヒント

認知スコアを上げるには

  • ✓ 公式サイトの構造化データを最適化
  • ✓ Wikipedia、業界メディアでの言及を増やす
  • ✓ ブランド名を含む質の高いコンテンツを発信
  • ✓ 業界レポートやランキングへの掲載を目指す

推奨度を上げるには

  • ✓ 顧客レビュー・事例を積極的に公開
  • ✓ 第三者による評価・推薦を獲得
  • ✓ 比較記事で強みを明確に訴求
  • ✓ アワード・認証を取得してアピール

ポジションを上げるには

  • ✓ 特定カテゴリでのリーダーシップを確立
  • ✓ 「〜といえば○○」のブランド想起を強化
  • ✓ SEO対策と連携してドメインオーソリティを向上
  • ✓ 業界キーワードとの関連性を高める

正確性を維持するには

  • ✓ 公式サイトの情報を常に最新に保つ
  • ✓ 価格・機能の変更を速やかに公開
  • ✓ 構造化データ（Schema.org）を正確に設定
  • ✓ 誤情報を見つけたら訂正リクエストを送信

よくある質問

Q: スコアはどのくらいの頻度で測定すべきですか？

週1回〜月2回の測定を推奨します。AIモデルは定期的にアップデートされるため、 継続的なモニタリングが重要です。大きな施策の前後には追加で測定することをおすすめします。

Q: 競合のスコアも測定できますか？

はい、同じAI応答に対して複数のブランド名で評価を実行することで、 競合比較が可能です。「競合比較」タブで一覧表示できます。

Q: 参照情報は必須ですか？

必須ではありませんが、正確性スコアの精度を上げるために推奨します。 公式サイトの情報、最新の価格表、プレスリリースなどを入力してください。

Q: 推奨度がマイナスになることはありますか？

はい、AIが否定的な文脈でブランドを言及している場合、推奨度スコアは -10点まで下がることがあります。この場合は、否定的な言及の原因を 調査し、対策を講じる必要があります。
